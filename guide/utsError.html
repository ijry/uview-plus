# UTS报错案例

uts报错涉及到原生等方方面面，确实有些问题比较难以定位，特此收集整理供参考。

# Undefined

提示props中定义了一个变量，结果编译报错不存在，出现这种情况有一种可能是多个组件实用mixins定义了props，然后导出时使用的变量名称冲突。 uview-plus是这样解决的，每个组件的props mixin都导出不同的名称避免冲突，如：

up-textarea/props.uts
export const propsTextarea = defineMixin({
	props: {
		// 输入框的内容
		modelValue: {
			type: String,
			default: crtProp['value']
		},
    }
})

up-tag/props.uts
export const propsTag = defineMixin({
	props: {
		text: {
			type: String,
			default: crtProp['value']
		},
    }
})
