# color 颜色值

此功能为uview-plus内部通过js提供的一些颜色值，可以用于通过js修改元素字体，背景颜色等一些场景，常用于uview-plus的各个组件中。
关于这些颜色值的具体描述，详见Color 色彩
使用方法：如使用primary颜色值，方法为：color['primary']

说明：这些通过JS调用的颜色值，也是能通过CSS调用的，二者等价。详见Color 色彩

# 平台差异说明

App（vue） App（nvue） H5 小程序
√ √ √ √

# 主题颜色

该主题颜色值，一共有5个，分别是primary、error、success、info、warning

import { color } from '@/uni_modules/uview-plus'
import { onLoad } from '@dcloudio/uni-app'
onLoad(() => {
	console.log(color['primary'])
})

import { color } from '@/uni_modules/uview-plus'
export default{
	onLoad() {
		console.log(color['error'])
	}
}

# 文字颜色

uview-plus一共提供了四个颜色值，具体请见组件部分Color色彩
分别有：mainColor、contentColor、tipsColor、lightColor、borderColor(边框颜色值)

import { color } from '@/uni_modules/uview-plus';
import { onLoad } from '@dcloudio/uni-app'
onLoad(() => {
	console.log(color['contentColor'])
})

import { color } from '@/uni_modules/uview-plus';
export default{
	onLoad() {
		console.log(color['contentColor']);
	}
}

# 背景颜色

uview-plus提供了一个浅灰的背景颜色值，该值为#f3f4f6

import { color } from '@/uni_modules/uview-plus';
import { onLoad } from '@dcloudio/uni-app'
onLoad(() => {
	console.log(color['bgColor'])
})

import { color } from '@/uni_modules/uview-plus';
export default{
	onLoad() {
		console.log(color['bgColor']);
	}
}
