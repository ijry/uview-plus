# Custom Ad Popup Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Replace the ad popup's Element UI dialog with a custom guarded popup inside the existing ad component.

Architecture: Keep all ad business behavior in adVip.vue, but replace Element UI DOM with custom overlay, panel, loading, notice, and buttons. Add runtime guard identifiers and a self-healing visibility guard that watches only this component's own nodes.

Tech Stack: VuePress 1, Vue 2 single-file component, axios, browser DOM APIs, localStorage.

# File Structure

  • Modify: docs/.vuepress/theme/components/adVip.vue
    • Owns ad route gating, API calls, custom popup rendering, notice UI, and anti-tamper guard.
  • No new runtime files.
  • No backend changes.
  • No changes to non-ad Element UI usages.

# Task 5: Implement Self-Healing Guard

Files:

  • Modify: docs/.vuepress/theme/components/adVip.vue

  • [ ] Step 1: Add style restore method

applyGuardStyles() {
  if (typeof document === 'undefined') return;
  const shell = document.getElementById(this.overlayId);
  const panel = document.getElementById(this.panelId);
  if (shell) {
    shell.style.setProperty('display', 'flex', 'important');
    shell.style.setProperty('visibility', 'visible', 'important');
    shell.style.setProperty('opacity', '1', 'important');
    shell.style.setProperty('pointer-events', 'auto', 'important');
    shell.style.setProperty('position', 'fixed', 'important');
    shell.style.setProperty('inset', '0', 'important');
    shell.style.setProperty('z-index', '2147483000', 'important');
  }
  if (panel) {
    panel.style.setProperty('display', 'flex', 'important');
    panel.style.setProperty('visibility', 'visible', 'important');
    panel.style.setProperty('opacity', '1', 'important');
    panel.style.setProperty('pointer-events', 'auto', 'important');
    panel.style.setProperty('position', 'relative', 'important');
    panel.style.setProperty('z-index', '2147483001', 'important');
  }
}
  • [ ] Step 2: Add node validation method
isGuardNodeVisible(node, type) {
  if (!node || node.getAttribute('data-guard') !== this.guardToken) return false;
  const style = window.getComputedStyle(node);
  const rect = node.getBoundingClientRect();
  if (style.display === 'none') return false;
  if (style.visibility === 'hidden' || style.visibility === 'collapse') return false;
  if (Number(style.opacity) < 0.2) return false;
  if (style.pointerEvents === 'none') return false;
  if (rect.width < 10 || rect.height < 10) return false;
  if (type === 'panel' && (rect.bottom < 0 || rect.top > window.innerHeight)) return false;
  return true;
}
  • [ ] Step 3: Add guard check method
checkDisplay() {
  if (!this.qrDialog || typeof document === 'undefined') return;
  const shell = document.getElementById(this.overlayId);
  const panel = document.getElementById(this.panelId);
  const visible = this.isGuardNodeVisible(shell, 'shell') && this.isGuardNodeVisible(panel, 'panel');
  if (visible) {
    this.guardFailures = 0;
    return;
  }
  this.guardFailures += 1;
  this.applyGuardStyles();
  if (this.guardFailures >= 3) {
    this.isBlocked = true;
    this.setNotice('请关闭广告屏蔽器支持我们，欢迎提交有质量的PR获取免弹窗广告权益。', 'error');
    document.documentElement.style.opacity = '0';
  }
}
  • [ ] Step 4: Add observer lifecycle
startGuard() {
  if (typeof document === 'undefined') return;
  this.stopGuard();
  this.guardFailures = 0;
  this.guardObserver = new MutationObserver(() => {
    this.checkDisplay();
  });
  this.guardObserver.observe(document.body, {
    childList: true,
    subtree: true,
    attributes: true,
    attributeFilter: ['style', 'class', 'id', 'data-guard']
  });
  if (!this.check) {
    this.check = setInterval(() => {
      this.checkDisplay();
    }, 2000);
  }
},
stopGuard() {
  if (this.guardObserver) {
    this.guardObserver.disconnect();
    this.guardObserver = null;
  }
  if (this.check) {
    clearInterval(this.check);
    this.check = null;
  }
}
