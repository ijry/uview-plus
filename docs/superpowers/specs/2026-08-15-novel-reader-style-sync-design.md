# 小说阅读器样式同步设计

## 背景

当前 `u-novel-reader` 已具备小说阅读、分页、目录、书签和设置能力，但组件样式只部分参考了 `uview-plus4`。示例页仍使用固定 `900rpx` 卡片容器，主题色和部分面板尺寸也与参考实现不一致。

更关键的是，当前组件会在 `.nvue` 页面使用，而若干横向 Flex 容器只声明了 `display: flex`，没有显式声明 `flex-direction: row`。Web 默认方向为横向，App nvue 原生布局默认方向可能为纵向，因此工具栏、设置项和目录项会出现平台间样式差异。

## 目标

- 保留当前 Vue3 API、事件、插槽和扩展设置项。
- 参考 `uview-plus4` 的 `.uvue` 实现补齐 App nvue 兼容样式。
- 同步工具栏、设置面板、目录和主题的主要视觉规格。
- 将示例页调整为全屏沉浸式阅读布局。
- 使用静态验证脚本防止关键样式再次缺失。

## 非目标

- 不替换当前阅读器状态、分页或持久化实现。
- 不删除字重、动画开关和完成按钮等现有能力。
- 不机械复制 `uview-plus4` 的 UTS 模板或组件 API。
- 不改动与小说阅读器无关的组件。

## 根因与策略

采用兼容式同步，而不是整体覆盖：以当前实现为主体，只迁移参考组件中与布局和视觉有关的规则。

1. 对所有语义上横向排列的 Flex 容器显式增加 `flex-direction: row`。
2. 对语义上纵向排列的容器继续显式保留 `flex-direction: column`。
3. 使用 `uview-plus4` `.uvue` 中更适合原生端的尺寸和对齐规则，避免依赖 Web 默认值。
4. 保留当前悬浮工具栏结构，将层级与参考实现统一为 `z-index: 10`。

## 组件样式

### 主容器

- 阅读器保持 `position: relative`、宽高 `100%` 和内容裁剪。
- 正文视口始终占满阅读器，不因工具栏显隐改变高度。
- 顶部和底部工具栏继续绝对定位，并统一使用层级 `10`。
- 根节点继续通过内联样式提供背景色和文字色，兼容不支持 CSS 变量的平台。

### 工具栏

- 工具栏行、按钮组和圆形按钮显式采用横向 Flex。
- 标题最大宽度参考原生端实现使用稳定像素值，避免 nvue 下视口单位差异。
- 保留当前悬停态、禁用态、进度条和安全区处理。

### 设置面板

- 同步参考实现的面板宽度、标题区内边距、关闭按钮尺寸和分区间距。
- 设置行、选项行、主题列表和主题按钮显式横向排列。
- 主题选项采用等宽卡片布局、`42px` 高度和 `8px` 圆角。
- 保留当前新增的字重、动画开关、提示文字和完成按钮，并沿用统一间距体系。

### 目录面板

- 面板高度改为跟随弹层 `100%`，避免固定视口高度造成溢出。
- 标题区使用原生端兼容的底部对齐方式。
- 目录项、索引、书签标题和书签内容显式横向排列。
- 同步标题字号、索引宽度和书签区域内边距。

### 正文区域

- 保留现有正文、分页和状态布局。
- 分页容器显式横向排列，状态容器保持纵向排列。
- 不改动文本排版、分页计算或点击区域行为。

## 主题

主题配置继续支持 `day`、`paper`、`green`、`night` 和 `dark`。

- 为每个主题补齐独立的 `active` 与 `disabled` 色值。
- `border` 色值与 `uview-plus4` 保持一致。
- JavaScript 主题令牌与 `theme-vars.scss` 使用相同值，避免内联变量覆盖主题样式后出现色彩不一致。

## 示例页

- 根容器改为全宽、全高、禁止溢出的沉浸式布局。
- 移除阅读器外部标题、按钮组、固定高度卡片和底部状态区。
- 保留模式切换能力，并通过 `toolbar-extra` 插槽放入顶部工具栏。
- 保留章节请求、进度、设置、书签和阅读时长等事件处理逻辑。

## 验证

更新 `scripts/verify-novel-reader-ui.mjs`，至少验证：

- 关键横向 Flex 容器包含 `flex-direction: row`。
- 顶底工具栏使用绝对定位和 `z-index: 10`。
- 五种主题均包含 `active` 与 `disabled` 色值。
- 设置主题项采用等宽 `42px` 卡片布局。
- 目录面板使用 `height: 100%`。
- 示例页使用全屏容器且不再包含固定 `900rpx` 阅读器框。

实施后运行小说阅读器现有四个验证脚本，并确保未引入与本次样式同步无关的修改。

## 验收标准

- App nvue 下工具栏、设置行和目录项均按预期横向排列。
- 阅读器在示例页中占满可用窗口。
- 工具栏显隐不改变正文高度。
- 五种主题的强调色、禁用色和边框色保持一致。
- 当前已有的设置项、事件和插槽继续可用。
