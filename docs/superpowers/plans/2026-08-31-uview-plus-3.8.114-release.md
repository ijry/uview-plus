- [ ] **Step 1: Start the actual publish exactly once in a hidden Git Bash background process**

Create the marker before process launch, then use `Start-Process -WindowStyle Hidden -PassThru` so the Windows PID can be monitored. Git Bash merges stdout and stderr into the ignored log:

```powershell
$marker = 'cachePath/publish-3.8.114.started'
if (Test-Path -LiteralPath $marker) { throw '3.8.114 publish already started; do not run again' }
New-Item -ItemType File -Path $marker -ErrorAction Stop | Out-Null
$publishArgs = @('-lc', 'cd /d/Repos/xyito/open/uview-plus && exec bash /d/Repos/xyito/config/hx-plugin-publish.sh /d/Repos/xyito/open/uview-plus/src/uni_modules/uview-plus --bump patch --notes-file /d/Repos/xyito/open/uview-plus/cachePath/notes.md > /d/Repos/xyito/open/uview-plus/cachePath/publish-3.8.114.log 2>&1')
$publishProcess = Start-Process -FilePath 'C:\Program Files\Git\bin\bash.exe' -ArgumentList $publishArgs -WindowStyle Hidden -PassThru
Set-Content -LiteralPath 'cachePath/publish-3.8.114.pid' -Value $publishProcess.Id -Encoding ascii
$publishProcess.Id
```

Do not execute this command a second time. The `.started` marker must remain present and block repetition.
