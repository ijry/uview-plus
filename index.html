快速接入

三步开始使用

使用 npm 或插件市场安装，几分钟即可跑通第一个页面。

  1. 01

    安装依赖

    在项目根目录执行 npm install uview-plus，也可以通过插件市场下载后导入项目。

  2. 02

    注册与配置

    在 main.js 中注册组件库，配置 easycom 自动引入，组件无需手动 import。

  3. 03

    开始使用

    在模板中直接书写 u- 组件，主题定制、暗黑模式与多语言开箱可用。

main.js
// main.js —— 注册 uview-plusimport uviewPlus from 'uview-plus'import App from './App' // #ifdef VUE3import { createSSRApp } from 'vue'export function createApp() {  const app = createSSRApp(App)  app.use(uviewPlus)  return { app }}// #endif
index.vue
