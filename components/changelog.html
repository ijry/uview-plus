# 更新日志

更新日志及升级指导

为减少重复工作，后续API变更等重大的日志（升级时请关注这些重大变化）在这里可以查看，常规更新日志请访问此链接查看 更新日志。

  • 3.8.X

    2026根据近期提交与插件 changelog 整理的重大更新（常规细节请看源码 changelog）：

    • 变更 3.8.139：uview-plus 转为付费授权（插件市场普通授权 99 元、源码授权 199 元），并彻底关闭开发文档站广告——不再有微信广告弹窗，也不再加载 Google AdSense，文档浏览不再被打断
    • 新增 3.8.138：新增 u-audio 音频播放器组件，基于 uni.createInnerAudioContext 实现，支持播放/暂停、进度条拖动、倍速切换、多源自动切换与 play/error 事件，App / H5 / 各小程序全平台可用；u-parse 的音频节点改用 u-audio 渲染（Vue3 已废除 <audio> 组件）
    • 修复 3.8.137：u-tabbar 等八个父子联动组件（tabbar / steps / checkbox-group / radio-group / grid / collapse / dropdown / swipe-action）修复抖音小程序等平台 watch 回调早于自身 created 执行时访问未初始化 children 的崩溃（#1065），u-tabbar-item 找不到父组件时改为最多 10 次、每次 100ms 的延迟重试并补注册到 parent.children，消除「必须搭配up-tabbar组件使用」误报并恢复抖音端吸顶联动；u-sticky 吸顶 top 值显式钉死 px，修复配置全局 unit: 'rpx' 的项目在非 375px 宽度设备上吸顶元素与导航栏之间出现间隙（#1063）；u-select 对齐复位并入打开的同一次渲染提交、溢出判断改为与对齐状态无关，修复奇偶次打开面板位置交替错误（#1061）；u-input 修复 firstChange 标记导致首次程序化赋值（弹窗选择回填）不触发表单验证的问题及 doBlur 小程序端报错（#726）；u-form 未配置 trigger 的校验规则不再被静默跳过、errorType="toast" 在自动触发校验时也能弹出提示（#726 / #614）；u-form-item 的 borderBottom 未显式设置时跟随 u-form 同名属性（#614）
    • 修复 3.8.136：u-goods-sku 的 close() 原 this.false = true 为无效赋值（误建 false 属性、弹窗从未真正关闭），改为 this.show = false 真正关闭弹窗，并将 popup 的 close/closed 事件经模板透传给父组件，避免 ref.close() 触发 popup 的 show watcher 补发导致父组件重复收到 close 事件；u-icon App 本地字体构建插件改为按包内相对路径后缀匹配，覆盖 npm（node_modules）/ pnpm 安装方式，修复 App 远程 @font-face 不被剥离的问题（#1069），App-Vue 改用原始 _www/static/app-plus/uview-plus/upicon.ttf 路径交由 view 层转换一次，修复云打包正式 APK 图标不显示的问题（#1069）
    • 新增 3.8.135：新增 u-lottie Lottie 动画组件，覆盖 H5 / App-Vue、微信小程序与鸿蒙多端渲染。H5 / App-Vue 基于 lottie-web SVG 渲染器，H5 端引擎按需加载、加载失败自动清理；微信小程序基于 lottie-miniprogram 画布渲染；鸿蒙通过 harmony-canvas-adapter 画布适配。支持 filePath（动画 JSON 地址，http(s)，H5 / App-Vue 额外支持本地静态路径）与 animationData（直接传 Lottie JSON 对象，优先级更高）两种数据来源，可配置 contentModel 填充模式（ScaleToFill / AspectFill / Center）、loop 循环播放与 autoplay 自动播放；实例方法提供 reload / playAnimation / pauseAnimation / resumeAnimation / cancelAnimation，statechange 事件统一回报 ready / play / pause / resume / stop / complete / error 状态（微信小程序从 event.detail 读取）。新增 u-upload 新增 mediaType 属性（默认 ['image', 'video']），accept 为 media 时透传给 chooseMedia 控制可选文件类型（image / video / mix）。修复 u-upload 的 chooseMedia 不再做平台编译判断，改为运行时检测接口是否存在，不存在时自动回退到 chooseImage，修复部分平台 accept="media" 直接报错的问题
    • 修复 3.8.134：修复 u-cropper 的三个问题。一、iOS 上底部操作栏与页面浮动按钮/标签重叠：画布高度减掉了底部安全区，而操作栏仍是 50px 贴在屏幕最底，两者之间露出一条约安全区高度的页面背景，页面上浮动的元素会从这条缝里透出来（安卓 safeAreaInsets.bottom 为 0，所以只有苹果机能看到）；现在操作栏高度改为 50px + 安全区并用 padding-bottom 让出，与画布严丝合缝，按钮也完整位于 home 指示条上方。二、quality 参数完全失效：5 处导出都把 fileType 硬编码为 png，PNG 是无损格式、没有质量档位；新增 fileType 属性（默认 png，可选 png/jpg），只有 jpg 才会按 quality 压缩，chooseImage 的 params 也可覆盖。三、质量归一化使用 parseInt，parseInt(0.5) 为 0 后被 || 0.9 改回 0.9，所有小数质量都被悄悄抬高；改用 parseFloat 并夹取到 0-1。升级注意：fileType 默认仍为 png，输出格式与升级前一致，不需要改代码；需要压缩体积时显式传 fileType="jpg" 并配合 quality
    • 修复 3.8.133：修复 u-number-keyboard 退格键在微信小程序下短按不删除内容、只剩长按连删有效的问题。根因是 @touchstart 上残留的 .stop 会编译成 catchtouchstart，把同一节点上的 tap 一起吞掉；同时补充 touchcancel 清理定时器，避免触摸被系统手势打断后长按连删空转。新增 u-toast 新增 overlay 属性（默认 true），设置 :overlay="false" 后遮罩由铺满全屏收缩为跟随内容大小并居中的浮动层，提示期间点击与滚动可穿透页面；show() 未显式传值时回落到该 prop，show({ overlay }) 仍然优先
    • 新增 3.8.132：u-goods-sku 新增 defaultSku 属性，支持默认选中的 SKU，并支持响应式更新与重置恢复（#1070）；新增 safeAreaInsetBottom 属性（默认 true），可关闭底部安全距离，并透传给 u-popup。修复 calc.div 改用 digit.divide 实现，避免依赖未定义的 xyutil，修复运行环境为空时的崩溃
    • 修复 3.8.130：修复 u-text 在微信小程序下的 v-bind="" is not supported. 编译报错，并恢复根节点属性继承，避免普通文本的 id、data-* 等属性丢失。升级注意：撤回 3.8.128 向内部分享按钮自动透传任意 data-* 属性的实现；需要自定义分享数据时，请使用原生 button 显式绑定 data-* 并设置 open-type="share"
    • 变更 3.8.129：u-navbar 在微信小程序端默认避让右上角原生胶囊按钮，避免右侧插槽、图标和文字被遮挡；新增 avoidCapsule 属性（默认 true），如需保留原有布局可显式设置为 false（#1058）
    • 新增 3.8.128：新增 u-video（up-video）视频播放器组件，统一封装 video 播放能力，支持弹幕（danmaku）、自定义进度条与控制层以及常见播放属性透传，覆盖 H5 / 小程序 / App；随包新增面向 AI 编码助手的 skills/uview-plus 技能包，含 setup、components、api、icons、pitfalls 参考文档
    • 修复 3.8.128：集中修复一批跨组件问题。u-list / u-list-item 新增 anchor 锚点滚动定位并修复 scrollIntoViewById 调用后不滚动（#671、#721）；u-calendar 修复关闭重开后副标题与月份不一致，并优化大 monthNum 下的渲染性能；u-select 完善面板指示器、自适应与多选回显；u-icon 字体加载失败后改由定时器重试，修复 u-search 输入后无法再次聚焦（#844）；u-dropdown 修复 nvue 下菜单宽度被压缩（#814）；u-collapse 修复展开后内容变高被裁切；u-cell 必填星号改用真实节点渲染，修复小程序与 nvue 下不显示；u-slider 修复 border-box 下的滑块错位；u-textarea 回车默认换行并支持 confirmHold；u-text 透传 data-* 属性；u-upload 透传 H5 端视频真实 File 对象；u-search 修复小程序端占位符颜色首屏不生效；u-cate-tab 优化大量图片首屏渲染与滚动联动；以及 u-picker、u-datetime-picker、u-grid、u-parse、u-number-keyboard、u-car-keyboard 与类型声明的多项修复
    • 修复 3.8.127：修复抖音小程序中 u-tabbar-item / u-steps-item 因父子组件生命周期顺序导致的崩溃。抖音小程序下子组件 created 可能早于父组件执行，此时父组件 children 数组尚未初始化，子组件 init() 访问 parent.children.indexOf 会抛 TypeError 并误报「必须搭配父组件使用」。现为 u-tabbar-item / u-steps-item / u-list-item 补齐 parent / children 守卫并在 mounted 补偿重试，共享 mixin getParentData() 也改为访问 children 前先判断父组件存在
    • 新增 3.8.126：新增 u-flex（up-flex）通用弹性布局容器组件，跨端同名同默认，作为页面 view 之上的一层弹性布局落点，免去每处手写 display:flex 与各类对齐样式。支持 direction 主轴方向、justify 主轴对齐（兼容 start / end 简写）、align 交叉轴对齐、wrap 换行与 gap 间距（任意单位），并暴露 click 事件
    • 修复 3.8.125：修复 u-signature 签名组件在 App 端无法绘制、笔迹画出后立即消失的问题。根因是画布上下文异步就绪未做握手、触摸坐标未换算到画布坐标系、以及每次 draw() 都会刷新绘图命令队列清空已画笔迹。现改为 touchMove 增量线段绘制并用 draw(true) 保留已绘制内容，坐标统一换算到画布坐标系，并新增画布 ready / initCanvas 握手避免首笔丢失。覆盖 APP-PLUS / APP-HARMONY / APP-NVUE，微信小程序与 H5 不受影响
    • 新增 3.8.124：App 端图标字体默认改用随包分发的本地字体（_www/static/app-plus/uview-plus/upicon.ttf），弱网或离线时不再丢图标；新增通用 Vite 插件入口 UpVite（libs/vite/index.js），不使用 Root 组件的项目单独引入即可复制字体，后续组件库新增构建期能力不需要再改业务项目的 vite.config
    • 变更 升级注意： 3.8.124 起 App 端默认优先加载本地字体。未引入 UpVite 的项目本地字体文件不存在，会自动回退 config.iconUrl，行为与升级前一致，不会丢图标；不希望使用本地字体可传 UpVite({ appStaticIconFont: false })。H5 与小程序不受影响
    • 新增 3.8.92：up-swipe-action-item 支持 scrolling / v-model:scrolling 和 @scrolling，横向滑动时可配合 page-meta 或 scroll-view 暂停页面/容器滚动，手势结束后自动恢复
    • 变更 升级注意： 3.8.91 起 u-text 默认 flex1 由 true 调整为 false，文本组件不再默认占满父级剩余空间；如果业务依赖旧版横向撑满、占位或对齐效果，请显式设置 flex1，或为外层/文本指定宽度。

    • 修复 H5 下 index.js 组件自动注册：移除对 import.meta.glob 的运行时函数判断，确保 Vite 编译期宏正常展开

    • 变更 up-button 非 nvue 普通按钮默认宽度由 100% 调整为 auto，避免横向布局挤压相邻内容；size="large" 仍全宽，需要全宽请显式设置 custom-style 或外层宽度
