# Sass报警@import

在sass1.8.0以上版本报错Deprecation Warning: Sass @import rules are deprecated and will be removed in Dart Sass 3.0.0. 因为新版本Sass的@use语法较为激进，如果升级为@use将会是破坏式更新，所以推荐将sass固定在以下版本结局报警。

"sass": "1.63.2",
"sass-loader": "10.4.1",

关于组件前缀说明

uview2使用u-和u--前缀，其中u--前缀的出现是为了防止与uni-app官方sdk中的组件重名冲突，uview-plus为了尽量降低大家升级迁移成本，目前也是兼容这两个前缀的。 不过由于u-前缀越来越凸显一些问题，比如u-slider似乎又在新版本SDK中被占用导致无法使用，结合uview-plus的名称因此我们支持也鼓励大家使用up-前缀，这样不仅能 避免冲突，还能降低心智负担(uview-plus中将全面启用up-前缀)。 同时大家也不用担心，就目前而言，以上前缀仅仅是一个easycom的规则配置即可，与核心代码关联不大，因此可以说大家喜欢用什么前缀都支持，只要你想，你甚至可以在几秒 钟内定义一个自己专属的前缀。 不过需要注意的是对easycom的修改可能不会实时生效，遇到不生效时建议重启项目。

# Hbuilder X方式

下载方式配置文档

如果您是使用Hbuilder X开发的用户，您可以在uni-app插件市场通过uni_modules的形式进行安装，此安装方式可以方便您后续在uni_modules对uview-plus进行一键升级。

  • 在uni-app插件市场右上角选择uni_modules版本下的使用HBuilderX导入插件，导入到对应的项目中即可。

注意： 此安装方式必须要按照下载方式安装的配置中的说明配置了才可用。


下载地址：https://ext.dcloud.net.cn/plugin?name=uview-plus


# NPM方式

npm方式配置文档

在项目根目录执行如下命令即可：

// 如果您的根目录没有package.json文件的话，请先执行如下命令：
// npm init -y

npm install uview-plus

// 更新
// npm update uview-plus

注意： 此安装方式必须要按照npm方式安装的配置中的说明配置了才可用，且项目名称不能有中文字符。

# 版本查询

有两种方式可以查询到正在使用的uview-plus的版本：

// 通过`console.log`打印的形式
console.log(uni.$u.config.v);

// 可以查阅uview-plus的配置文件得知当前版本号，具体位置为：
/uview-plus/libs/config/config.js
